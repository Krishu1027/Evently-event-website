# Evently – Event Management Website

A responsive website to explore events, search and filter them, and register.

## Features
- Hero section, event cards, search and category filter
- Event details popup with registration form
- JavaScript form validation + confirmation message
- Responsive (mobile, tablet, desktop)

## Bonus Features
- 🌙 Dark / Light mode (remembered after refresh)
- ⏳ Live countdown timer on every event
- ✨ Card, button and popup animations
- 💾 Registrations saved in Local Storage (with cancel option)

## Tech Used
HTML5, CSS3, JavaScript (no libraries)

## How to Run
Open `index.html` in a browser. To deploy, push to GitHub and enable GitHub Pages (or use Netlify / Vercel).

## How It Works
- `index.html` – page structure
- `style.css` – styling, themes (CSS variables), animations
- `script.js` – event data, search/filter, validation, countdown, Local Storage, theme toggle
